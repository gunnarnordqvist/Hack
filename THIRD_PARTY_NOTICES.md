## Body figure (web/vendor/bodypaths.js)

The path data of the front and back figure and of the hand, leg and back close-ups is **not drawn by this project**. It is generated by
`tools/build_body_paths.py` from the npm package `react-body-map` 1.1.0, read as text (nothing from the package is executed).
Region ids, sides and the SNOMED CT meaning of each region are ours; the geometry is theirs. The cross-section of the head and neck
(`web/headsection.js`) is the exception: it was drawn for this project from scratch and is not from any third party.

## SNOMED CT

SNOMED CT content is not stored in this repository. The public web site reads it at run time from a FHIR terminology server
(HL7 Nordics, `tx-nordics.fhir.org`) in the visitor's browser. SNOMED CT is copyright SNOMED International; the Swedish
module is maintained by the Swedish National Release Center. Follow the SNOMED CT licence terms of your country when you reuse
what the server returns.
